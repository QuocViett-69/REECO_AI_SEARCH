# API Example Fixtures

These files are frontend-ready examples for the frozen Step 7.7 contract. They use real, sanitized
CS655 catalog values and are validated against the exported `@reeco/shared` Zod schemas.

Collection fields in the list, detail, and search examples are deliberately shortened for readability.
They are schema-valid examples, not exhaustive snapshots of the live record and not golden ranking
outputs. The server remains the source of truth for current data and result ordering.
